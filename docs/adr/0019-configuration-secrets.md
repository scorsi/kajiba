# ADR 0019 — Configuration and runtime secrets

Status: Accepted — 2026-10-11 (revised 2026-10-24: declared identity Accepted; field table and validation rules accepted)

## Context

Server and runner are deployed exclusively through Nix (NixOS, nix-darwin). Secrets are provided as files by the deployment's secret manager. Environment variables easily leak into logs and `ps`.

## Decision

- One **TOML file** per component, **generated by the Nix module** (never written by hand), passed through `--config <path>`. The schema is a single Rust struct (serde); the module options mirror it one to one, each field a typed option.
- **No secret in the file**: only paths (`*_file`) read at startup or on demand, readable by the service user; never logged. Token **hashes** are not secrets and are written in the file (0014).
- **Unknown fields are rejected** (`deny_unknown_fields`); a field named like a secret without `_file` (`token`, `secret`, `password`, `key`) is unknown, and the error names the `_file` field to use.
- No configuration through environment variables, except `RUST_LOG` (overrides `log.level` when set) and the runtime's standard variables.
- Safe defaults in the code; the Nix module only writes what differs.
- Reload: service restart, no hot reload.
- **Validation**: `kajiba-server config check <path>` is **structural** — parse, types, ranges, durations, URLs, names (0021), loopback-only `metrics.listen`, SSH keys parse, hashes are 64 hex characters, every scope known, every runner and credential name valid — and touches no file; the NixOS module runs it at build time on the generated file. `config check --files` also opens every `*_file`. At startup the server runs both and exits with `config-invalid{err}` (0022) naming the field or file.

### Server fields

Durations are strings `<n>s|m|h|d`.

| Field                                       | Default                      | Meaning                                                            |
| ------------------------------------------- | ---------------------------- | ------------------------------------------------------------------ |
| `state_dir`                                 | `/var/lib/kajiba`            | 0012 layout                                                        |
| `http.listen`                               | `127.0.0.1:8080`             | plaintext listener behind the reverse proxy (0005)                 |
| `http.public_url`                           | required                     | external URL; WebAuthn relying party and origin (0014), clone URLs |
| `http.reflection`                           | `false`                      | gRPC reflection                                                    |
| `ssh.host`, `ssh.port`                      | host of `public_url`, `2222` | shown in SSH clone URLs (0004, 0021)                               |
| `log.level`                                 | `info`                       | `tracing` filter (0022)                                            |
| `metrics.listen`                            | absent                       | loopback `/metrics` listener; absent = none (0022)                 |
| `auth.session_ttl`                          | `7d`                         | 0014                                                               |
| `auth.enrollment_ttl`                       | `15m`                        | 0014                                                               |
| `users.<name>.is_admin`                     | `false`                      | declared user (0014)                                               |
| `users.<name>.ssh_keys`                     | `[]`                         | auth keys, OpenSSH public key lines                                |
| `users.<name>.signing_keys`                 | `[]`                         | commit and tag signing keys                                        |
| `users.<name>.tokens.<token>.sha256`        | required                     | hex SHA-256 of the PAT                                             |
| `users.<name>.tokens.<token>.scopes`        | required                     | 0014 scopes                                                        |
| `users.<name>.tokens.<token>.expires`       | absent                       | RFC 3339                                                           |
| `runners.<name>.token_file`                 | required                     | shared secret (0008)                                               |
| `mirror.credentials.<name>.token_file`      | required                     | GitHub PAT (0011)                                                  |
| `mirror.reconcile_interval`                 | `1h`                         | 0011                                                               |
| `ci.log_retention`, `ci.artifact_retention` | `14d`                        | 0010                                                               |
| `dump.dir`, `dump.keep`                     | `/var/lib/kajiba-dumps`, `7` | 0016                                                               |

### Runner fields

| Field                         | Default                  | Meaning                            |
| ----------------------------- | ------------------------ | ---------------------------------- |
| `name`                        | required                 | runner name declared on the server |
| `url`                         | required                 | forge URL                          |
| `token_file`                  | required                 | shared secret                      |
| `backends`                    | `["nix"]`                | 0009                               |
| `tags`                        | `[]`                     | 0008                               |
| `max_jobs`                    | `1`                      | concurrency                        |
| `state_dir`                   | `/var/lib/kajiba-runner` | checkouts, temporary files         |
| `log.level`, `metrics.listen` | `info`, absent           | 0022                               |

### Complete server example

```toml
state_dir = "/var/lib/kajiba"

[http]
listen = "127.0.0.1:8080"
public_url = "https://forge.example.org"

[ssh]
port = 2222

[metrics]
listen = "127.0.0.1:9431"

[users.alice]
is_admin = true
ssh_keys = ["ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAINdamAGCsQq31Uv+08lkBzoO4XLz2qYjJa8CGmj3B1Ea user@example.org"]
signing_keys = ["ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAID1AF8PoQ4lakrcKp00bfrycmCzPLsSWjMDNVfEq9GYM user@example.org"]

[users.alice.tokens.ci]
sha256 = "9f2c1e0a4b7d3f8e6a5c2b1d0e9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4c3d2e1f"
scopes = ["repo:read", "ci:trigger"]

[runners.build-1]
token_file = "/run/secrets/kajiba-runner-build-1"

[mirror.credentials.github]
token_file = "/run/secrets/kajiba-github-token"

[ci]
log_retention = "14d"
```

### Complete runner example

```toml
name = "build-1"
url = "https://forge.example.org"
token_file = "/run/secrets/kajiba-runner-build-1"
backends = ["nix"]
tags = []
max_jobs = 1
state_dir = "/var/lib/kajiba-runner"

[log]
level = "info"

[metrics]
listen = "127.0.0.1:9432"
```

A unit test deserializes the server and runner examples; the module's nixosTest runs `config check --files` on the generated file.

## Consequences

- The configuration is versioned in the deployment repository and reproducible; a typo is a build failure, not a runtime surprise.

## Rejected alternatives

- CLI flags for everything: unreadable in a Nix module.
- Environment variables: secret exposure, no structure.
- Accepting unknown fields with a warning: a misspelled option silently keeps its default.
