# ADR 0005 — API: gRPC, grpc-web for the browser, a single port

Status: Accepted — 2026-10-09 (revised 2026-10-24: packages per 0020, Rust CLI, TLS by a reverse proxy)

## Context

The API is a deliverable in its own right, consumed by the frontend (SPA) and the CLI (Rust, 0007). Desire for lightness and strong typing.

## Decision

- The **`.proto`** files are the source of truth for the public contract, the runner protocol (0008) and the local socket (0003). Packages per 0020: `kajiba.v1`, `kajiba.runner.v1`, `kajiba.hook.v1`, `kajiba.admin.v1`.
- **tonic** server with **tonic-web** (grpc-web) for the browser; **connect-web** client on the SvelteKit side (grpc-web protocol), **tonic** client on the CLI side (generated by `kajiba-proto`).
- Streams: server-streaming for CI logs and status tracking. No bidirectional streaming on the public API (unsupported by browsers).
- **A single HTTP port** (axum router): gRPC/grpc-web, read-only git smart HTTP, `/raw/<owner>/<name>/<ref>/<path>` (for `fetchurl`, 0021), frontend assets, `/healthz`, `/readyz`, WebAuthn ceremonies in JSON (the libraries speak JSON). `/metrics` is a separate loopback listener (0022).
- Call auth: session cookie (browser) or bearer token (CLI, 0014), checked by a single interceptor.
- **TLS**: terminated by a reverse proxy in front of the forge (genkan, for example); the forge listens in plaintext on `http.listen`, loopback by default. The public URL (`http.public_url`, 0019) is what the proxy serves.

## Consequences

- No REST: debugging with `grpcurl`; gRPC reflection is enabled by configuration (`http.reflection`, off by default).
- TS and Rust clients are generated; no manual type duplication.
- The reverse proxy must pass HTTP/2 (gRPC from the CLI) and HTTP/1.1 (grpc-web, git smart HTTP) to the plaintext listener, and allow long-lived responses (log streams, clones).

## Rejected alternatives

- REST + OpenAPI: more curl-able, but two schemas to maintain (API + runner) and less typing.
- GraphQL: nothing to gain.
- TLS in the forge: certificate management duplicated in every service; the reverse proxy already does it.
